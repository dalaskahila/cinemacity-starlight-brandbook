# Cinemacity Starlight & 1927

Animated presentation, version 26.

[View the presentation](https://dalaskahila.github.io/cinemacity-starlight-brandbook/presentation/)

Press Arrow Down or Space once to advance one slide, and Arrow Up to return. Photos continue moving while each slide is displayed. Scroll and section dots also work. The bottom-right button opens fullscreen. The Screening Rooms carousel has a pause control. Reduced-motion preferences are respected.

All presentation text, layouts and animation code match the approved local version. Photos are optimized web derivatives; original files are retained separately. Averia Serif Libre is bundled with its OFL license.
